# Flare 插件目录

[English](README.md) · 简体中文

[plugins.json](plugins.json)提供 Flare IM 插件的公开元数据。版本标识目录快照，分发方式和平台字段描述该版本可接入的 SDK 平台。

[目录工作流](.github/workflows/catalog.yml)校验公开字段、分发模式及插件 ID 的唯一性。制品访问、构建输入和租户审批由插件维护者与平台管理。

开发自有插件从 [Flare 插件 DevKit](https://github.com/flare-im/flare-plugin-devkit) 开始，查看公开契约和 Manifest 示例。
